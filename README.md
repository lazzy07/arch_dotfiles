# My Archlinux dotfiles (Final Version)

## This setup will configure my applications the way I want them to be.
This configuration uses symlinks using linux stow

To install stow

```bash
sudo pacman -S stow
```

Then clone the content of this repository into a folder inside your `home` directory.

```bash
git clone https://www.github.com/lazzy/arch_dotfiles.git dotfiles
```

Finally, you can run
```bash
stow .
```

## Managing monitors
I used [nwg-displays](https://www.github.com/nwg-piotr/nwg-displays) to find the perfect monitor layout for my PC.

## Changing the wallpaper
To change the wallpaper and regenerate the matugen color scheme, use the following script.

```bash
matugen-wall.sh <wallpaper_path>
```

## OpenDeck (Stream Deck)
`.config/opendeck` holds the profiles for my Stream Deck (`sd-A00SA6042PO7SO`), stowed like everything else. Two things are intentionally **not** tracked (see `.gitignore`):

- `.config/opendeck/plugins/` — installed plugin binaries/deps. Reinstall these from the OpenDeck plugin store on a new machine:
  - OpenDeck Starter Pack (`com.amansprojects.starterpack`)
  - PipeWire Audio Control (`com.sfgrimes.pipewire-audio`)
  - Essentials for Spotify (`com.ntanis.essentials-for-spotify`) — needs re-authenticating with Spotify after install
- `.config/opendeck/settings/` — per-plugin settings, which for the Spotify plugin includes OAuth tokens/client secret. Regenerated by re-authenticating.

Profile layout (bottom-right key always jumps back to Home, except on Home itself):

- **Home** — jump to Dev / Spotify / Audio, plus quick launchers (terminal, files, browser) and a mic/master mute toggle.
- **Dev** — terminal, LazyGit, Neovim, mic/master mute.
- **Spotify** — playback controls, now-playing info, volume.
- **Audio** — master and mic volume up/down/mute.
